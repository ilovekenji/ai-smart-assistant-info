AI智慧助理

透過 LINE 整理外勤工作、行程、郵件與待辦。

這是什麼工具？

AI智慧助理主要供擁有者本人處理工作查詢、行程、郵件及提醒。經允許的 LINE 群組可使用部分受限查詢及問答功能；Gmail 僅供授權者於受限的私聊流程操作，不向群組開放。這個網站提供功能與資料使用說明，不提供公開註冊或付費訂閱。

Google 資料的用途

  • Gmail：搜尋郵件及依指令產生摘要，經再次確認才將選取郵件移至垃圾桶。
  • Google Calendar：管理已授權且與助理連結的行程。
  • Google Drive：處理已指定的工作檔案。指定 Excel 欄位可能依工作完成紀錄更新；Office 檔案查詢為唯讀。

Gmail 摘要會把選取郵件的必要內容交由 OpenAI API 處理；另行使用 Gemini 時，該次指令與工具內容也可能交由 Gemini API 處理。資料使用及保存方式請閱讀隱私權政策。

授權與控制

本助理僅在既有授權範圍內執行功能。擁有者可在 Google 帳戶的第三方連線設定撤銷授權。撤銷不會自動刪除已存在的郵件、日曆事件、LINE 訊息或本機備份。

本頁沒有 Google 登入按鈕，也不收取密碼、驗證碼或授權 Token。
