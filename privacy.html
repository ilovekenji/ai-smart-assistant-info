隱私權政策

更新日期：2026-11-05

適用範圍與管理者

管理者顯示名稱為「AI智慧助理」。助理主要供擁有者本人使用；經允許的 LINE 群組有部分受限查詢及問答功能。Gmail 僅供授權者於受限的私聊流程操作，不向群組開放。本網站不提供公開註冊，公開說明頁不會授予助理存取權。

存取的資料與用途

  • LINE：使用者識別碼、訊息、指令與確認內容，用於限制使用身分、執行工作、回覆及提醒。
  • Gmail：依指令搜尋郵件，讀取郵件識別碼、寄件者、收件者、主旨、日期、摘要與正文，提供搜尋結果及郵件摘要。一般摘要最多選取 6 封，最近郵件重點最多 10 封，每封送往摘要的正文最多 5,000 字元。現有功能不下載郵件附件，也不定期備份整個信箱。
  • 郵件移除：依授權者指令列出候選郵件，再經確認移至 Gmail 垃圾桶；本助理不呼叫略過垃圾桶的永久刪除。依 Gmail 規則，郵件移入垃圾桶後通常於 30 天後永久刪除，也可由使用者提前清除。
  • Google Calendar：處理已連結事件的標題、描述、日期時間與事件識別碼，依指令建立、更新或刪除行程。
  • Google Drive／Office：讀取已授權且指定的客戶 Excel，依既有工作完成回報更新指定防毒欄位並保存稽核；主人另行指定 Office 查詢時，唯讀擷取桌面同步的指定 Office 檔案供 Gemini 回答。這不代表任意讀寫整個雲端硬碟。
  • 工作資料：本機保存工作待辦、行程關聯、出勤查詢結果與必要狀態，用於工作管理及提醒。

Gmail 使用 https://www.googleapis.com/auth/gmail.modify 權限，以支援讀信及經確認移至垃圾桶。此權限本身比目前功能廣；目前程式未實作寄信，不能把這項授權稱為唯讀。本網站不新增或變更任何權限。

資料的接收服務

  • Google：透過 OAuth、API 或既有桌面同步，執行授權、讀信、垃圾桶操作、日曆及指定檔案處理。
  • OpenAI API：Gmail 摘要會傳送授權者要求，以及選中郵件的寄件者、主旨、日期及受長度限制的正文。程式設定 store=False，以停用回應物件儲存。OpenAI API 資料預設不供模型訓練，除非帳戶另行選擇分享；本助理不將 Google 使用者資料加入該類分享。濫用監控紀錄依適用政策通常仍可能保存最多 30 天，法律或安全例外另依政策處理；這不表示零留存。
  • LINE：搜尋結果、郵件候選清單、摘要與提醒會回覆到授權者的 LINE 私聊，可能留在聊天紀錄。
  • Gemini API：現有 Gmail 摘要程式不直接呼叫 Gemini；另行使用 Gemini 的指令與 Office 工具內容，會進入該次 Gemini 處理。
  • ngrok：轉送 LINE Webhook 到本機，包括 LINE 指令及驗證標頭；它不是 Gmail API 的郵件來源。
  • GitHub Pages：網站預計使用 GitHub Pages 託管；公開後，GitHub 會依其隱私政策處理訪客 IP 等連線資料。本三頁網站本身不設登入、表單、追蹤碼、分析工具或廣告，也不承載郵件、工作週報或下載憑證。

第三方的處理、存取與保存依各服務條款、資料使用政策及實際帳戶設定辦理。本助理不宣稱所有資料都留在本機，也不宣稱第三方已清除資料。

保存、保護與刪除

工作紀錄、事件關聯、處理狀態、必要日誌與授權資料保存在擁有者管理的電腦，依本機存取控制保護。授權資料及復原備份亦由管理者採取本機存取控制與備份保護措施，避免未經授權的存取。

垃圾郵件候選清單會在本機資料庫保存郵件 ID、寄件者、主旨與日期，供確認操作使用。操作有效期為 10 分鐘；到期不代表資料庫或備份立即實體刪除。一般 Gmail 搜尋及摘要不另行將每封完整正文存成助理資料庫紀錄，但原 Gmail、LINE 聊天、服務商處理紀錄、必要日誌與備份仍可能保有相關內容。

目前沒有統一承諾所有資料在固定天數後自動刪除。擁有者可在 Google 第三方連線設定撤銷授權，並另外處理本機資料、備份、聊天與各服務的資料清理。撤銷授權只影響後續存取，不會自動刪除既有事件或其他副本。

Google API 資料使用限制（Limited Use）

AI智慧助理對透過 Google API 取得的資訊之使用與移轉，遵守 Google API Services User Data Policy，包括 Limited Use 要求。這些限制也適用於由該資料產生的摘要及其他衍生資料。

  • 資料僅用於提供或改善使用者可見、已說明的郵件、行程及工作檔案輔助功能。
  • 只在取得使用者同意且為提供上述功能所必要時，傳送必要資料給 OpenAI API、LINE 等處理服務；其他移轉僅限安全需要、遵守法律，或符合政策且事先取得明確同意的業務移轉。
  • 不販售 Google 使用者資料，不將其用於廣告、資料仲介、信用或貸款評估，也不將其用於訓練或改善通用 AI／機器學習模型。
  • 除授權者使用自己的資料外，不允許其他人員閱讀 Google 使用者資料，除非已取得使用者對特定資料的明確同意、為安全或法律所必要，或符合政策對彙總匿名資料的有限例外。

外部服務僅可在上述用途及限制內處理資料。資料保存、濫用防護及依法處理仍可能發生；不代表零留存，也不代表已獲 Google 驗證或認證。
